# GPG fixture for the mailer test suite

This directory holds a deterministic GPG keypair used by Cerebrate's
mailer tests (`GpgMailerTest`, the `--encrypt` branch of
`SendEmailCommandTest`). It is **test-only** — never deploy it.

## Files

- `setup_keyring.sh` — rebuilds the `keyring/` homedir from the committed
  `.asc` files. Idempotent: wipes any existing homedir.
- `fixture-public.asc` — the public key (committed).
- `fixture-secret.asc` — the secret key (committed; test-only).
- `keyring/` — generated by `setup_keyring.sh`; gitignored.

## Identity

| Field      | Value                                  |
|------------|----------------------------------------|
| User-ID    | `Cerebrate Test <test@cerebrate.test>` |
| Key-Type   | RSA 2048, sign primary + encrypt subkey |
| Passphrase | `cerebrate-test`                       |
| Trust      | ultimate (set by `setup_keyring.sh`)   |

## Why ownertrust is forced to "ultimate"

Crypt_GPG does not expose a way to pass `--trust-model always` to gpg.
Without ownertrust on the fixture key, gpg blocks every encrypt call
on `untrusted_key.override` (a `GET_BOOL` status line Crypt_GPG never
answers). Setting ownertrust to `ultimate` after import sidesteps this.

## Regenerating the keypair

If the key ever expires (or you need to rotate it):

```bash
cd tests/Helper/gpg
rm -rf keyring _gen
mkdir _gen && chmod 700 _gen
cat > _gen/spec <<EOF
Key-Type: RSA
Key-Length: 2048
Key-Usage: sign
Subkey-Type: RSA
Subkey-Length: 2048
Subkey-Usage: encrypt
Name-Real: Cerebrate Test
Name-Email: test@cerebrate.test
Expire-Date: 1y
Passphrase: cerebrate-test
%commit
EOF
GNUPGHOME="$(pwd)/_gen" gpg --batch --pinentry-mode loopback --gen-key _gen/spec
GNUPGHOME="$(pwd)/_gen" gpg --armor --export 'test@cerebrate.test' > fixture-public.asc
GNUPGHOME="$(pwd)/_gen" gpg --armor --pinentry-mode loopback --passphrase 'cerebrate-test' \
    --export-secret-keys 'test@cerebrate.test' > fixture-secret.asc
rm -rf _gen
./setup_keyring.sh
```

Commit `fixture-public.asc` and `fixture-secret.asc`. Keep the
passphrase value in this file.
